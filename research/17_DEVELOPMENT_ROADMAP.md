# Development roadmap — proposed

1. **Reliable core:** one language and framework, selected GitHub repository read access, instrumented test app, event ingestion, commit-specific code search, evidence viewer and investigation with abstention. Gate: demonstrable real incident with linked evidence and secure access revocation.
2. **Verified repair:** reproducible fixtures, isolated runner, patch diff, deterministic regression tests, explicit approval and draft PR. Gate: reproduce baseline, verify after patch and show test failures distinctly; inability to reproduce is a supported outcome.
3. **Differentiation:** consented synthetic journeys, accessible layered explanations and evidence-backed dependency graph. Gate: working signal and validated user need before visualization.
4. **Advanced intelligence:** deployment risk and selective parallel agents only after baseline evaluation demonstrates incremental value, acceptable latency and cost.

No release dates or staffing estimates are asserted without a team and scope.
