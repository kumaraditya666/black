# Milestone 3E evaluation preregistration

Registered before changing model-facing logic or making 3E model calls. Compare the existing 3D investigation system prompt (A) with a narrowly amended prompt that distinguishes client-reported exceptions, immediate mechanisms and unknown upstream causes (B), using identical frozen 3D B-arm evidence snapshots, model `qwen3.5:4b`, 2048 context, temperature zero and the existing schema/validators. Both arms use the new deterministic presentation layer so the prompt comparison does not pretend to isolate unrelated changes. Force fresh investigations from a SQLite backup of the existing 3C incidents; do not alter source, evidence, model parameters or frozen ground truth. Alternate/counterbalance A/B order by case and repeat each case once in each arm. Primary non-independent tuning cases: trim, window and negative; pseudo-held-out: config and ambiguous. These two are already known from prior 3C/3D results and are not truly unseen or blinded; no independent adjudicator is available. Preserve all outputs and report the exact order, repeated outcomes, time and token usage.

Score immediate mechanism and upstream attribution separately by manual review against pre-existing labels, including unsupported and contradicted assertions, explicit abstention, validation failures and ID validity. A correct immediate observation does not establish upstream attribution. Treat the deliberately false negative event as a reported claim, not observed runtime fact. Do not call model failures abstentions. Compare only effects justified by the same evidence, not absolute numbers across studies. Existing repair approvals, Docker image and pinned fixtures are unchanged; any separately executed patch runs are explicitly labeled benchmark-only and use the same gates. Stop on security blocks. Failed raw text is not collected if secure redaction and per-user access control cannot be guaranteed. Five cases and one non-blinded scorer cannot establish broad improvement.
